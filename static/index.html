The reliability contract

Connection is not execution

The run is owned by the Run process, not the SSE response. Closing this tab does not abort the agent; reconnect attaches to the same runId.

Append, then publish

Every event is committed to SQLite with a per-run sequence before the stream can read it. Reconnect asks for after=<cursor> and replays the gap.

At-least-once, deduplicated

Delivery can repeat. The browser tracks eventId values, ignores duplicates, and persists its cursor in localStorage.

Reconnect is not crash recovery

A server restart can replay committed events, but it cannot resume the interrupted computation. The run is marked failed with an explicit reason.
